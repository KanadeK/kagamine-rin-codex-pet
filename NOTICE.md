# Notice and provenance

This is an unofficial, non-commercial fan project. Kagamine Rin / 鏡音リン is
a Piapro Character managed by Crypton Future Media, Inc.

The pet artwork was generated as a new chibi fan depiction using OpenAI's
built-in image generation workflow. The generation specification used only
the character's well-known design traits: blonde bob, oversized white bow,
cyan eyes, white-and-yellow sailor-inspired top, black shorts, and dark
arm/leg warmers. It did not copy or redistribute official image pixels.

No Kagamine Rin voice, voicebank, song, lyrics, logo, Project DIVA asset,
Project SEKAI asset, or third-party fan artwork is present in this repository.
