# Artwork QA evidence

The files here are retained release evidence for the exact final atlas.

- `atlas-validation.json` records topology, transparency, and color-key gates.
- `contact-sheet.png` and `look-directions.png` support visual inspection.
- `direction-blind-*.json` records three isolated A/B reviews, the strict
  majority, and hidden-key validation.
- `direction-semantics.json` records explicit evidence for all 16 directions.
- `look-continuity.json` records measured adjacent-frame changes.
- `final-visual-qa.json` is the post-repair independent full-atlas verdict.

The two rejected row-10 semantic reports are kept as auditable failure
evidence. Rejected source images and generator cache paths are intentionally
not published.
