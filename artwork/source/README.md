# Retained artwork sources

This directory keeps the reproducible, publishable inputs for the fan-art
pipeline:

- the complete generation and repair prompts;
- deterministic layout guides;
- the approved canonical base;
- the v2 request contract and look mechanics;
- a sanitized generation manifest with hashes and rejection history.

No official Crypton/Piapro artwork, logo, voice, song, lyric, game asset, or
third-party fan art is present. Generator cache paths and machine-local paths
are intentionally excluded.
